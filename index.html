How Minimax works

Two players take turns. MAX tries to maximise the score; MIN tries to minimise it. The search explores legal future moves and backs up the best achievable value.

MAX nodereturns the largest child value
MIN nodereturns the smallest child value
Alpha-Beta pruning: keeps bounds α and β. When α ≥ β, the remaining siblings cannot change the result, so the search skips them. The selected move remains optimal.

04 · The actual C++ algorithm

The browser games invoke functions compiled from this C++ source into WebAssembly. The full source is included in the download.

static int ttt_search(int* b, int player, int depth, int alpha, int beta, int ai, int use_ab) { ++ttt_node_count; const int w = ttt_winner(b); if (w == ai) return 10 - depth; if (w == -ai) return depth - 10; if (ttt_full(b)) return 0; if (player == ai) { // MAX int best = -100000; for (int i = 0; i < 9; ++i) if (b[i] == 0) { b[i] = player; const int value = ttt_search(b, -player, depth + 1, alpha, beta, ai, use_ab); b[i] = 0; // undo move if (value > best) best = value; if (use_ab) { if (best > alpha) alpha = best; if (alpha >= beta) { ++ttt_cutoff_count; break; } } } return best; } int best = 100000; // MIN for (int i = 0; i < 9; ++i) if (b[i] == 0) { b[i] = player; const int value = ttt_search(b, -player, depth + 1, alpha, beta, ai, use_ab); b[i] = 0; // undo move if (value < best) best = value; if (use_ab) { if (best < beta) beta = best; if (alpha >= beta) { ++ttt_cutoff_count; break; } } } return best; }
