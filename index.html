01 / The big idea

What is Minimax?

Minimax is a decision-making algorithm used in two-player, turn-based games. It assumes both players play optimally: one tries to maximize the score, while the other tries to minimize it.

PLAYER 01

MAX — maximize

MAX represents the AI or player trying to obtain the highest possible score. It selects the child with the largest value.

PLAYER 02

MIN — minimize

MIN is the opponent. It assumes the opponent will choose the move that gives MAX the lowest possible score.

THE RESULT

Best guaranteed move

By exploring future possibilities, Minimax chooses the move with the best outcome against an optimal opponent.

MAX node: max(child values)   |   MIN node: min(child values)

03 / Under the hood

The algorithm, in plain language

Minimax is a recursive algorithm. When it reaches a terminal state, it returns that state's score. Otherwise, it evaluates the children and chooses the best value for the current player.

function minimax(node, isMaximizing):
  if node is terminal:
    return evaluate(node)

  if isMaximizing:
    best = -∞
    for child in children(node):
      best = max(best,
        minimax(child, false))
    return best

  else:
    best = +∞
    for child in children(node):
      best = min(best,
        minimax(child, true))
    return best

This is language-independent pseudocode. “Terminal” means the game has ended or the search has reached its depth limit.

COMPLEXITY

How expensive is it?

Let b be the average number of legal moves per position and d be the search depth.

Time: O(bd)

Space (depth-first): O(bd)

What about alpha-beta pruning?

Alpha-beta pruning keeps track of bounds (α and β). If a branch cannot affect the final choice, the algorithm stops exploring it. The answer remains the same, but fewer nodes may need evaluation.

α = MAX's best so far
β = MIN's best so far
Prune when α ≥ β
